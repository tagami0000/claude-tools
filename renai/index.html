        全資料に共通する約束ごと

        GROUND RULES

        どの資料を読むときも、先にここを前提にします。

        ⚠ いちばん先に来るのは相手の同意

        • はっきりした「いいよ」がなければ進めない。迷い・沈黙・話をそらすのはYESではない。
        • 断られたら引く。言い換えや理屈で断りを崩そうとしない。
        • 判断できない状態の相手とは進めない。酔いすぎている、断りにくい状況にある（手を引かれている・店の前まで来ている等）ときも同じ。
        • 路上では進路をふさがない・触れない。強い拒絶には1〜2回で退く。

        このハブの要約ルール

        • 内容は削らない。元資料の項目はすべて残し、文章だけを要旨に言い換える。
        • 原文を丸写ししない。原文と16字以上続けて一致しないかを機械でチェックしてから載せる。
        • 断られた後に押し切るための台本は図解しない。その章は構成と著者の注意事項だけを載せる。
        • 個人の復習用。元資料は購入者向けのため、全ページを検索エンジンに載せない設定（noindex）にしている。
        資料の足し方このページの更新メモ
        1. 要約ページ（HTML）を、このページと同じ renai/ フォルダに置くページの上部と末尾に <a href="index.html">← 恋愛まとめへ戻る</a> を入れ、<meta name="robots" content="noindex, nofollow"> も付ける。
        2. このファイル（renai/index.html）の DOCS 配列に、下のひな形を1件足すカード・件数・分類タイルの数・横断検索は自動で増える。章へのリンクは a に #見出しのid を書く。
        3. 分類は CATS の id（mind / approach / contact / date / close / extra）から選ぶどれにも当てはまらない資料が増えたら、CATS に1件足せば分類も増やせる。
        4. main にコミットして push する1〜2分で公開サイトに反映される。
        {
  id: 'xxx',                       // 英数字の短いID（重複しないもの）
  title: '○○ 図解',
  href: '○○_図解.html',             // renai/ の中のファイル名
  kind: 'PDF要約',
  source: '著者『書名』',
  pages: 0, patterns: 0, cards: 0,  // 不明なら書かなくてよい
  created: '2026-11-01',
  color: 'var(--c5)',              // --c1〜--c7 / --cx
  tags: ['…', '…'],
  desc: 'ひとこと説明',
  sections: [                      // 章ごとの入口（横断検索に使う）
    { t: '第1章 …', a: '#ch1', cat: 'approach', n: 30, kw: '検索用の語',
      g: [['グループ名', '#グループのid']] },
  ],
},
